# user-insights-cli

A Node.js command-line tool that fetches users, posts, and todos from
JSONPlaceholder (https://jsonplaceholder.typicode.com) and prints a report
per user, followed by summary statistics.

## Requirements
- Node.js v24.21.0 or newer

## Setup
```bash
git clone https://github.com/TalhaNaru/week-1.git
cd week-1
```
There are no dependencies to install.

## Run
```bash
npm start
```

## Error handling
If the API can't be reached, the script prints a friendly message and exits with code 1.
